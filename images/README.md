# Imagens do site

As imagens atuais são **ilustrações fictícias em SVG**, criadas especialmente para este rascunho (arte original, sem direitos autorais de terceiros). Elas são geradas pelo script `tools/make_images.py`:

```
python3 tools/make_images.py
```

Para usar fotos reais, basta salvar os arquivos nesta pasta e trocar a extensão `.svg` pela da foto em `index.html` e `styles.css`.

| Arquivo | Onde aparece |
| --- | --- |
| `hero.svg` | Banner principal |
| `cake-classic-wedding.svg`, `cake-birthday.svg`, `cake-floral.svg`, `cake-statement.svg` | Signature Cakes |
| `reputation.svg` | Faixa "A Reputation Built on Sweetness" |
| `portfolio-1.svg` … `portfolio-6.svg` | Grade do portfólio (a 1ª é a foto alta) |
| `testimonials.svg` | Fundo da seção "Kind Words" |
| `cta.svg` | Fundo da faixa "Every cake tells a story" |
